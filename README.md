# 📊 Sellers Dashboard

Dashboard en Streamlit con el desempeño de ventas de los vendedores por región.

## Cómo correrlo

```
pip install -r requirements.txt
streamlit run sellers_app.py
```

## Archivos

- `sellers_app.py`: la app de Streamlit
- `sellers.xlsx`: los datos de los vendedores
- `requirements.txt`: las librerías que necesita la app
